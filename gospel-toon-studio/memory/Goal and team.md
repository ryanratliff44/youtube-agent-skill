# Goal and team
Back to [Gospel Toon Studio](Gospel%20Toon%20Studio.md)

**Goal:** short vertical cartoon videos about the life of Jesus and other Bible stories, posted to TikTok,
YouTube Shorts and Instagram Reels. Ryan wants to make many (eventually thousands) over the coming years, so it
must be a repeatable pipeline, not one-off work.

**The team** (Claude Code agents in `gospel-toon-studio/.claude/agents/`), run by Claude as Producer (`CLAUDE.md`):
- **Scriptwriter**: Gen Z "storytime" script, scripture quotes verbatim (KJV), shot list pinned to narration words.
- **Narrator**: voice (Kokoro `am_liam`) and word-timed captions.
- **B-roll artist**: backgrounds (now: Unreal Engine clips or AI pictures).
- **Editor**: Remotion assembly: background + flat 2D characters + captions + voice.
- **Publisher**: uploads; dry run first, posts only after Ryan says yes.

**Channel rules** (`bible/CHANNEL_BIBLE.md`): scripture first, mark tradition as tradition, reverent (humor from
people's reactions, never from Jesus/God), no gore, no scripture text on screen (references go in the description).
